# Solmara — Open-World Crime Sandbox

A small, original low-poly crime sandbox set in a sunlit coastal city. Walk the streets, take a car, evade patrols and deliver packages.

## Run

From the repository root, run `node serve.ts` and open http://localhost:8080. Click New Game to begin.

## Controls

WASD move or drive · drag mouse to orbit · E enter/exit and interact · Shift run / handbrake · Space jump / handbrake · F punch · Q draw pistol · click shoot · R reset vehicle · M mute · Esc pause.
